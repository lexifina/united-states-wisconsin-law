# 33.12 Scope.
Any proposed activity by a district which does not involve an application for state aids or an application for a ch. 30 permit is exempt from subch. III. If a proposed activity by a district involves an application for state aids, subch. III applies. If a proposed activity by a district involves an application for a ch. 30 permit, subch. III shall apply only if the department determines that the activity requiring the permit is an integral part of a lake rehabilitation project.
History: 1973 c. 301.
